## Definition

One unit of memory: a Markdown file with frontmatter under .memory/<type>s/, or .memory/archive/<type>s/ once archived, of type decision, learning, question, reminder, concept or note.

## Notes

A handover is not an entry: it has no ID and is overwritten per branch.
